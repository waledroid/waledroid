### 🚀 Featured Projects

#### [IsiDetector — AI Parcel Detection & Sorting Platform](https://github.com/waledroid/IsiDetector)
> **Stack:** `Python` • `PyTorch` • `TensorRT` • `OpenVINO (NNCF)` • `ByteTrack` • `Docker` • `FastAPI`  
> Real-time conveyor parcel detection and instance segmentation (`mAP@50 ≈ 0.96`). Features an automated model quantization pipeline (`FP16` and static `INT8` QDQ), sub-millisecond line-crossing detection, and low-latency UDP triggers to industrial sorting PLCs within a 600–1100 ms execution window.
>
> 🔗 [Interactive Case Study](https://portfolio-waledroid.netlify.app/isidetector.html) • [GitHub Repository](https://github.com/waledroid/IsiDetector)

#### IsiMonitor 3D — Industrial Multi-Camera Perception & Digital Twin
> **Stack:** `GStreamer` • `ONNX Runtime` • `OpenVINO` • `MQTT / UDP` • `Three.js` • `FastAPI`  
> Multi-camera 2D/3D warehouse tracking with real-time metric digital twin for automated guided vehicles (AGV) and warehouse management systems (WMS). Accompanied by **isiCal** (guided multi-camera extrinsic/intrinsic calibration studio using ChArUco & Multical) and **isiGen** (synthetic data generation engine based on SDXL, ControlNet, and SAM2).
>
> 🔗 [Interactive Case Study](https://portfolio-waledroid.netlify.app/isimonitor3d.html)

#### ROSBot Harmony — Autonomous Robotics & Mobile Fleet Planning
> **Stack:** `C++` • `RTAB-Map` • `ROS 2` • `MoveIt` • `PyTorch`  
> Autonomous navigation, Visual SLAM, multi-robot coordination, and motion planning for mobile robot fleets.

#### NanoSAM / ViT Knowledge Distillation for Edge Devices
> **Stack:** `PyTorch` • `TensorRT` • `NVIDIA Jetson Orin Nano`  
> Compression of heavy Vision Transformer (ViT) image encoders through knowledge distillation and TensorRT engine optimization, reducing latency by 40% and increasing segmentation throughput by 25%.
